# Android SDK integration

This sample uses Android `ANDROID_ID` as a stable app-scoped device identity. On Android 8+ it is scoped by signing key, user and device and generally survives reinstall when the same signing key is used. It can change after factory reset, signing-key change, user/profile change or ROM behavior.

Add `INTERNET` permission. Copy `LicenseManager.java` and `LicenseVerifier.java` into your app package. Configure `PRODUCT_ID` as `APP_A` or `APP_B`, server URL, and the public JWK generated by `scripts/generate-signing-key.mjs`.

Call `activate(code)` once. For permanent license, save the returned signed token in app-private storage; verify it locally at every launch with `LicenseVerifier.verifyPermanentToken(...)`. If token is missing after reinstall, ask the user for the original activation code and call `restore(code)`. The same Android ID is required.

For trial access, do not cache a permanent grant. Call `checkTrial(code)` online before enabling trial features and periodically while in use. Server is authoritative for expiry. Do not allow trial use when offline.

This is an integration sample, not a complete UI. Never embed ADMIN_KEY or SIGNING_KEY in the APK.
